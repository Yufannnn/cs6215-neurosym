\section*{AI Usage Statement}

This project made substantial use of AI assistance, as the course permits, and we describe it phase by phase. % YUFAN: please check and edit every sentence marked [confirm] so that it states what you actually did.

\paragraph{Project planning.}
The topic was refined over several rounds with GPT Pro in ChatGPT, moving from an initial command-injection idea to a literature-grounded revision toward path traversal with the five-arm design, and then to the resolution of the open protocol decisions. The student chose the direction, compared alternatives and approved the final plan and protocol decisions. [confirm]

\paragraph{Implementation and experiments.}
Claude Code by Anthropic wrote the implementation under the student's direction, including the Semgrep rule, evidence extractor, recognizers, gate, prompts, pipeline, tests, diagnostic programs and label validator, and it also ran the experiments and generated the tables. The design decisions recorded in the artifact's decision log were proposed by the assistant or by GPT Pro and reviewed by the student. [confirm] They include the D/EC boundary, the strong baseline policy, the family-grouped development split, mechanical label validation and the post-hoc EC+ extension. The models evaluated in the experiments, \texttt{qwen3-coder-next} and \texttt{qwen3.5:9b}, were accessed through NUS SoCLaaS and served only as objects of study.

\paragraph{Analysis and writing.}
Claude Code drafted this report from the saved experimental outputs. Every number in the tables is generated by scripts from the stored run directories, and no result was entered by hand. The student reviewed the claims, edited the text and is responsible for the final submission. [confirm]

\paragraph{Review.}
GPT Pro also reviewed the finished artifact adversarially, and its counterexamples and claim corrections were applied as the versioned correction in Section~\ref{sec:correction}, with the report text narrowed to match.

\paragraph{Safeguards.}
The protocol was frozen and tagged in version control before any arm was run on test data. The artifact stores every model reply in the run directories and a stability log, and it stores the token counts and backend fingerprint of every request in a call log. Prompts are rebuilt deterministically from the code and the inputs, and the full response cache, which is needed only for offline replay, is not published. Development-time iterations, the post-review correction and post-hoc analyses are labelled as such throughout.
